# Association El Badr - Frontend

## Project Overview

This project is the frontend interface for the Association El Badr facility management system.

The website provides a modern and responsive interface for patients and administrators to access the association's services, manage reservations, and navigate through the different sections of the platform.

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Responsive Web Design
- Flexbox
- CSS Grid

## Pages

- **Homepage** (`index.html`)
  - Introduction to Association El Badr
  - Presentation of available services
  - Navigation to the different sections

- **Login** (`login.html`)
  - User login interface

- **Register** (`register.html`)
  - New user registration interface

- **Dashboard** (`dashboard.html`)
  - User reservation management

- **Reservation** (`reservation.html`)
  - Accommodation reservation form

- **Admin Panel** (`admin.html`)
  - Administrative interface

## Features

- Responsive design for desktop, tablet, and mobile
- Modern and clean user interface
- Navigation between different pages
- Login and registration interfaces
- Reservation interface
- Dashboard interface
- Administrative interface
- Interactive buttons and form elements
- Hover effects and visual feedback
- French-language interface
- Font Awesome icons

## Design

The frontend uses a professional blue-based color palette with accent colors.

The interface focuses on:

- Clear navigation
- User-friendly forms
- Responsive layouts
- Consistent typography
- Accessible and readable content
- Interactive UI elements
